# Microsoft Store Submission Runbook

AX Studio is submitted as an unpackaged Win32 NSIS application. Do not convert
the current release to MSIX without separately validating local model
sidecars, MCP child processes, extensions, file access, the local API server,
and updater behavior.

## Partner Center prerequisites

- Use a verified Company account for **DEFAI Private Limited**.
- Reserve the product name **AX Studio** before preparing listing artwork.
- Have company counsel approve [`privacy.md`](privacy.md) and
  [`terms.md`](terms.md) before submission.
- Host the approved documents at stable public HTTPS URLs and update
  `web-app/src/constants/external-links.ts` if those URLs differ from the
  repository copies.
- Disclose live generative AI and the downloadable model, extension, MCP, and
  cloud-provider behavior in the listing and certification notes.

## Build

Run the **Microsoft Store Builder** workflow manually with an existing stable
tag version. The workflow:

1. validates the Store configuration;
2. builds signed offline NSIS installers for x64 and ARM64;
3. verifies both outer Authenticode signatures;
4. silently installs, launches, audits installed PE signatures, and uninstalls
   the x64 package on a clean Windows runner; and
5. emits a 90-day `ax-studio-microsoft-store-submission-<version>` artifact
   containing both installers and `SHA256SUMS.txt`.

For local Windows packaging, use:

```powershell
yarn validate:microsoft-store
yarn build:tauri:microsoft-store
```

The Store configuration in
`src-tauri/tauri.microsoftstore.conf.json` overrides the normal online
WebView2 bootstrapper with Tauri's `offlineInstaller` mode. The Store build is
therefore larger than the normal GitHub installer.

## Immutable hosting

Upload each workflow output to a version-specific HTTPS path on publisher-owned
storage. A recommended shape is:

```text
https://downloads.example.com/ax-studio/microsoft-store/2.0.3/AX.Studio_2.0.3_x64-store-setup.exe
https://downloads.example.com/ax-studio/microsoft-store/2.0.3/AX.Studio_2.0.3_arm64-store-setup.exe
```

Replace `downloads.example.com` with the approved production host. Enable
storage immutability or fail uploads when the object already exists. Never use
the normal GitHub release upload path for Partner Center packages because that
release lane intentionally supports `--clobber` during recovery.

Use `/S` as the EXE installer parameter in Partner Center. Submit separate x64
and ARM64 package URLs with the matching architecture. Each new application
version requires new URLs and Store certification; never replace a submitted
binary in place.

## Listing copy requirements

The first paragraph should state that AX Studio is a local-first desktop AI
workspace and that cloud providers require user-configured accounts and may
receive prompts, attachments, and conversation context.

Include this live-AI disclosure or equivalent approved wording:

> AX Studio displays live content generated by local and third-party AI models.
> AI output may be inaccurate or inappropriate. Review outputs before relying
> on them and use the in-app reporting link to report safety concerns.

Partner Center fields:

- Privacy policy: the approved public version of `privacy.md`.
- License terms: the approved public version of `terms.md`.
- Support: `https://github.com/defai-digital/ax-studio/issues/new/choose` or an
  approved company support portal.
- AI-content reporting: the in-app link and GitHub issue form provided by this
  repository.
- Minimum display: 1024 × 800 until the UI is validated at a smaller height.
- Platforms: Windows 10/11 x64; add Windows ARM64 only after physical-device
  sign-off.

Prepare at least four current screenshots showing onboarding, cloud/local model
selection, a conversation with visible tool execution, and model/runtime
management. Do not show real API keys, personal data, or unlicensed third-party
branding.

## Manual release sign-off

- Install and uninstall on clean Windows 10 and Windows 11 x64 machines.
- Test on physical Windows ARM64 hardware before enabling the ARM64 listing.
- Validate upgrade from the previous Store-listed version using the in-app
  updater.
- Test at 100%, 150%, and 200% display scaling and at 1366 × 768.
- Confirm privacy, terms, support, release, and AI-report links open correctly.
- Confirm local-only mode stays local and each cloud/MCP connection clearly
  identifies the selected external service.
- Record the Partner Center package URLs and SHA-256 values in the release
  evidence before submission.
