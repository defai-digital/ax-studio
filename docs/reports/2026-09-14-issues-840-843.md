## 修改明细

### [#840：简单算术返回 Python 样式及错误答案](https://github.com/defai-digital/ax-studio/issues/840)

读取了正文和两条补充评论，覆盖 `2+2`、`9 + 8`、`9 - 8`、`14- 7 =`。现有系统提示词明确要求计算写 Python，确实会把普通算术引向代码回答。

- 修正提示词：简单算术直接作答，仅复杂计算或明确要求代码时使用 Python。
- 增加严格受限的两数四则计算路径，在正常聊天流中返回纯文本答案，不调用模型生成或工具，不附带旧的模型性能元数据。
- 使用 BigInt 分数计算，支持有符号整数、小数、可选等号及乘除符号。输入总长、数字位数和结果小数位数均有限制，不使用 `eval`。
- 只有最后一条用户消息、单一文本部分且整段匹配表达式时才适用。带解释/代码要求、附件、复合表达式、除零或无法精确结束的小数除法，继续交给正常聊天处理。
- 四个报告案例分别返回 `4`、`17`、`1`、`7`；同时验证 `0.1+0.2` 和超出 Number 安全整数范围的精确加法。

### [#841：分屏连续提问卡死、退出](https://github.com/defai-digital/ax-studio/issues/841)

检查确认：分屏模型选择器原来共用全局模型选择，并通过 `updateCurrentThreadModel` 修改路由当前会话。右侧选择模型可能改到另一侧；上下文扩容也漏传了右侧会话模型。发送入口则没有等待异步 handoff 完成。

- 给模型选择器传入明确的 threadId，从该会话解析模型与提供商，渲染时不再写入全局选择。
- 用户选模只更新目标会话；路由、设置面板及上下文扩容绑定该会话的模型。
- 发送入口等待异步 handoff，期间保持防重复提交状态；会话发送链在落盘前检查本会话忙碌状态，另一侧忙碌不阻塞当前侧。
- 捕获异步发送拒绝，避免成为未处理的 renderer Promise rejection。
- 隔离桌面测试覆盖右侧连续 5 轮和两侧并发发送，检查每侧上游历史长度与模型、四个后续算术答案及持久化。

模拟模型下，修改前的基础连续提问也没有触发原始进程退出；因此这些修复的证据是确认的跨会话状态风险和回归结果，而不是对原始崩溃的前后复现证明。可读的本机应用事件/崩溃目录检查未找到可归因的 AX Studio 崩溃记录，也不能据此断言从未崩溃。

### [#842：上下文设置失焦，输入转到模型搜索](https://github.com/defai-digital/ax-studio/issues/842)

设置齿轮原本与模型按钮一起包在 `PopoverTrigger` 中。点击齿轮会同时触发设置 Sheet 与模型搜索 Popover，搜索框的延迟聚焦与 Sheet 焦点管理发生冲突。

只把模型选择按钮作为 Popover 的触发器，设置齿轮成为旁边的独立控件。使用真实 Radix 组件及 Electron 窗口验证：打开设置不打开搜索弹层，输入框可输入并保留 `16384`，焦点仍在输入框。

### [#843：方向键不能调用搜索历史](https://github.com/defai-digital/ax-studio/issues/843)

原 `recent-searches` 保存的是打开过的会话 ID，不是搜索词，因此没有将该数据直接解释成查询文本。

- 新增共享搜索历史 hook，并接入聊天搜索、模型选择器和模型中心；侧栏搜索入口使用同一个聊天搜索对话框。
- 每个搜索区域独立保存最近 20 条查询，去重、限制单条长度，容忍无效存储数据；不记录输入过程的每一个字符前缀。
- `↑` 从最近查询向前回溯，`↓` 向后并最终恢复当前草稿，不循环越界；修改召回内容后可继续编辑或重新搜索。
- 聊天搜索已有结果导航时保留原有方向键行为；空查询/无结果时可直接召回历史，也可用 `Alt+↑` 明确进入历史导航。进入历史导航后 `↑/↓` 连续浏览；忽略 IME 输入中的按键。
- 测试覆盖草稿恢复、编辑、建议导航兼容、历史边界、去重以及旧会话 ID 数据不受影响。
