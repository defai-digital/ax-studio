# AX Studio 本地聊天与运行安全修复报告

日期：2026-09-10。基线提交：`9a054a8e`。
交付分支：`fix/local-chat-and-runtime-safety-20260910`。

## 范围与环境

本次合并首次聊天故障修复、Windows 本地构建修复，以及后续审计确认的五项问题和一项条件性会话问题。验证环境为 Windows、Node.js 24.20.0、Electron 源码构建及本机 Ollama。这里的构建成功指可运行的桌面构建，不表示生成或安装了独立安装包。

## 修复结果

| 问题 | 原因与修复 | 验证 |
| --- | --- | --- |
| 发送消息出现 `ServiceHub not initialized or model/provider missing` | 未选择模型时使用 `defaultModel('')`，产生模型 ID 有值但提供商为空的会话。发送前校验选择并保留输入；优先使用当前会话提供商；空覆盖值回退有效选择；区分缺少选择与提供商已删除。 | 发送入口、transport 回归及此前实际桌面发送验证。 |
| Ollama 模型无法走正确加载路径 | Ollama 使用已运行服务的 HTTP 端点注册到代理，不再调用缺失的内置 Ollama 引擎。 | model-session 回归；真实 qwen3:4b 经本次构建代理完成流式回答。 |
| Windows 扩展常量注入不匹配 | 将扩展目录统一为 Vite 使用的正斜杠路径，避免 Windows 分隔符导致注入规则失效。 | Vite 配置回归和完整桌面构建。 |
| 更改数据目录未迁移数据 | 仅允许空目标目录；复制前后计算文件清单与 SHA-256，检查源数据是否变化；校验后才更新配置。保留原目录作为恢复副本。拒绝相互嵌套路径及链接/目录联接。 | 真实临时目录测试，包含非空目标、嵌套路径、联接及配置提交失败。 |
| API key 明文保存在 localStorage | 将 `api_key` 和 `settings.api-key.controller_props.value` 从持久化元数据剥离，通过 Electron 系统加密保存；启动恢复到内存。后台空值不再覆盖密钥；显式修改、清空和删除提供商会更新安全存储。 | 凭据单元测试；隔离 Electron 验证旧数据迁移、磁盘密文、重载及定时刷新后提供商仍带凭据。 |
| factory reset 可能删除自选目录中的无关文件 | 仅接受默认应用目录或有迁移标记的目录，只删除已知应用数据项；删除前检查链接，保留其他文件。重置后继续使用已清理目录，避免重新加载迁移前的恢复副本。 | 保留 personal.txt、拒绝任意自选目录、链接目标不受影响等测试。 |
| 推理字段被拼成正文 | Electron SSE 代理原样保留事件；前端保留 `reasoning`/`reasoning_content`，交给 SDK 分别处理。 | 真实 HTTP SSE 字节保留测试及前端字段归一化回归。 |
| 配置超时大于 30 秒仍提前失败 | 移除首个响应头等待的 30 秒上限，使用配置值；等待超时返回 504，客户端取消仍单独处理。 | 真实上游延迟 31 秒、配置 40 秒时返回 200；配置 1 秒时返回 504。 |
| 同一组件切换 sessionId 可能复用旧 transport | transport 随 sessionId 更换或恢复该会话的缓存实例，并更新配置效果与会话绑定。普通路由通常会重新挂载；此次修复覆盖原来遗漏的同组件切换场景。 | hook 重渲染回归确认第二会话使用独立 transport。 |

## 使用行为与边界

- 数据迁移保留恢复副本，因此需要额外磁盘空间。失败的目标副本也保留用于检查，配置仍指向原目录。迁移期间请停止会修改数据的操作；检测到复制期间变化会拒绝切换。
- 重置仅清理 `threads`、`llamacpp`、`ax-engine`、`ax-serving` 和 `app.log` 等明确的应用项，不保证删除自定义目录中所有未知文件。未经标记的历史自选目录会拒绝重置，应先迁移到空的专用目录。
- 密钥仍需在运行进程内存中使用。此修复消除上述字段在当前 localStorage 记录中的明文，并采用系统加密持久化；不声称对旧数据库页、系统备份或外部副本完成安全擦除。系统加密不可用时拒绝保存提供商密钥并提示失败；纯浏览器模式不提供桌面持久化能力。
- 本机 qwen3:4b 仍可能把思考文本和 `</think>` 直接放入上游 `content`；这是模型/模板的文本输出，无法凭结构化字段归一化可靠识别。本次修复保证不再主动把结构化推理字段改写成正文，不承诺隐藏模型自行输出的文字。
- 响应超时覆盖等待响应头阶段，不新增整个生成过程的总时长或流空闲超时。
- 构建存在原有的动态/静态混合导入及大分块提示；不影响本次构建完成。测试通过不代表不存在其他尚未发现的问题。
